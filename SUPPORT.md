- [README.md](README.md) — kurulum ve hızlı başlangıç
- [KULLANIM_KILAVUZU.md](KULLANIM_KILAVUZU.md) — ayrıntılı Türkçe kılavuz

## Hata bildirimi

Hata bildirimi için GitHub issue formunu kullanın:

**https://github.com/emrullahalkac72-beep/AptozaQ3/issues/new/choose**

Lütfen şunları ekleyin:

- AptozaQ3 sürümü
- Windows sürümü ve mimarisi
- FFmpeg sürümü (`ffmpeg -version`)
- Hatayı yeniden üretme adımları
- Beklenen ve gerçek davranış
- Ekran görüntüsü / kısa video
- Varsa FFmpeg hata çıktısının son satırları

## Özellik önerisi

**Feature request** issue formunu kullanın. Önerinin hangi sorunu çözdüğünü ve
nasıl bir kullanıcı deneyimi istediğinizi açıklayın.

## Soru ve tartışma

- GitHub Discussions şu anda kapalıdır. Hata olmayan sorular için **Question**
  issue şablonunu kullanın.
- Hata olmayan genel sorular için issue açmadan önce README/FAQ kontrol edin.
