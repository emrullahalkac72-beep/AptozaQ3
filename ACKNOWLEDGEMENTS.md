# Teşekkürler

AptozaQ3, açık kaynak topluluğunun emeğiyle geliştirilmiştir. Bu projede
doğrudan veya dolaylı katkısı bulunanlara teşekkür ederiz.

## Geliştirici

- **Emrullah ALKAÇ** — proje sahibi, tasarım ve geliştirme

## Temel açık kaynak bileşenler

| Bileşen | Kullanım | Lisans |
|---|---|---|
| [Rust](https://www.rust-lang.org/) | Uygulama dili ve araç zinciri | MIT / Apache-2.0 |
| [egui](https://github.com/emilk/egui) | Anlık mod (immediate mode) GUI | MIT / Apache-2.0 |
| [eframe](https://github.com/emilk/egui/tree/master/crates/eframe) | Masaüstü uygulama çatısı | MIT / Apache-2.0 |
| [FFmpeg](https://ffmpeg.org/) | Medya kodlama, filtreleme ve dönüştürme | LGPL/GPL (yapılandırmaya göre) |
| [xcap](https://github.com/nashaofu/xcap) | Ekran ve pencere yakalama | MIT |
| [image](https://github.com/image-rs/image) | Görsel kodlama/çözme | MIT / Apache-2.0 |
| [serde](https://serde.rs/) / [serde_json](https://github.com/serde-rs/json) | Ayar ve proje serileştirme | MIT / Apache-2.0 |
| [rfd](https://github.com/PolyMeilex/rfd) | Yerel dosya seçiciler | MIT |
| [global-hotkey](https://github.com/tauri-apps/global-hotkey) | Global kayıt kısayolları | MIT / Apache-2.0 |
| [chrono](https://github.com/chronotope/chrono) | Tarih/saat biçimlendirme | MIT / Apache-2.0 |
| [tempfile](https://github.com/Stebalien/tempfile) | Güvenli geçici dosyalar | MIT / Apache-2.0 |
| [crossbeam-channel](https://github.com/crossbeam-rs/crossbeam) | Thread'ler arası iletişim | MIT / Apache-2.0 |
| [windows-sys](https://github.com/microsoft/windows-rs) | Win32 API bağlantıları | MIT / Apache-2.0 |
| [ab_glyph](https://github.com/alexheretic/ab-glyph) | Metin ölçümü/çizimi | Apache-2.0 / MIT |
| [webbrowser](https://github.com/amodm/webbrowser-rs) | Bağlantıları varsayılan tarayıcıda açma | MIT / Apache-2.0 |
| [ico](https://github.com/mdsteele/rust-ico) | Uygulama simgesi | MIT |

Tam bağımlılık ağacı ve sürümler için `Cargo.lock` dosyasına bakın.

## Topluluk

- Hata bildiren, özellik öneren ve test eden tüm kullanıcılara.
- Türkçe dokümantasyon ve çeviri katkısında bulunanlara.
- Açık kaynak bakımcılarına ve sponsorlarına.
