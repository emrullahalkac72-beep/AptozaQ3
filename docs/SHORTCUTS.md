# Klavye Kısayolları

AptozaQ3 hem uygulama içi kısayolları hem de global kayıt kısayollarını
destekler. Global kısayollar uygulama arka planda olsa da çalışır.

## Global kayıt kısayolları

| Eylem | Varsayılan | Değiştirilebilir |
|---|---|---|
| Kayıt başlat | `F9` | ✅ |
| Duraklat / devam et | `F10` | ✅ |
| Durdur | `F11` | ✅ |
| Ekran görüntüsü | `F8` | ✅ |
| Çizim modunu aç/kapat | `F7` | ✅ |

Değiştirmek için **Ayarlar → Klavye Kısayolları** bölümünü kullanın. Bir
kısayola tıklayıp yeni tuş kombinasyonuna basın. Çakışan veya geçersiz
kombinasyonlar için hata mesajı gösterilir.

> Global kısayollar bazı oyunlarda veya yönetici olarak çalışan uygulamalarda
> çalışmayabilir. Bu durumda AptozaQ3'ü normal kullanıcı oturumunda çalıştırın
> veya kayıt düğmelerini kullanın.

## Uygulama kısayolları

### Genel

| Eylem | Kısayol |
|---|---|
| Yeni proje | `Ctrl+N` |
| Proje aç | `Ctrl+O` |
| Kaydet | `Ctrl+S` |
| Farklı kaydet | `Ctrl+Shift+S` |
| Dışa aktar | `Ctrl+E` |
| Geri al | `Ctrl+Z` |
| Yinele | `Ctrl+Y` veya `Ctrl+Shift+Z` |
| Çizim modunu aç/kapat | `F7` |
| Ekran görüntüsü | `F8` |
| Kayıt başlat | `F9` |
| Duraklat / devam | `F10` |
| Durdur | `F11` |

> Metin alanına yazarken `Ctrl+Z`, `Ctrl+S` gibi kısayollar metin alanına
> gider; uygulama kısayolları devre dışı kalır.

### Timeline

| Eylem | Kısayol |
|---|---|
| Oynat / duraklat | `Space` |
| Başa dön | `Home` |
| Sona git | `End` |
| Zaman çizelgesini yakınlaştır | `+` veya `=` |
| Zaman çizelgesini uzaklaştır | `-` |
| Seçili öğeyi sil | `Delete` veya `Backspace` |
| Oynatma başlığında böl | `S` |
| Geri al | `Ctrl+Z` |
| Yinele | `Ctrl+Y` / `Ctrl+Shift+Z` |
| Projeyi kaydet | `Ctrl+S` |
| Dışa aktarma penceresi | `Ctrl+E` |

`S` yalnızca timeline sekmesinde ve `Ctrl`/`Shift` basılı değilken çalışır.
Böylece `Ctrl+S` ile kaydetme çakışmaz.

### Çizim modu

| Eylem | Kısayol |
|---|---|
| Çizim modunu kapat | `Esc` veya `F7` |
| Çizimi geri al | `Ctrl+Z` |
| Çizimi yinele | `Ctrl+Y` / `Ctrl+Shift+Z` |
| Araç panelini aç/kapat | Üst araç çubuğundaki 🧰 düğmesi |

Çizim modu açıkken timeline dışındaki sekmelerde `Ctrl+Z` / `Ctrl+Y` çizim
geçmişine yönlenir. Timeline sekmesinde bu kısayollar proje geçmişini kullanır.

### Kayıt sırasında

| Eylem | Kısayol |
|---|---|
| Kayıt başlat | `F9` |
| Duraklat / devam | `F10` |
| Durdur | `F11` |
| Ekran görüntüsü | `F8` |
| Çizim modu | `F7` |

Kayıt sırasında çizim yapmak için `F7` ile çizim modunu açın. Çizimler hem
ekranda hem kayıt karesinde görünür.

## Kısayol atama

1. **Ayarlar** sekmesine gidin.
2. **Klavye Kısayolları** bölümünü açın.
3. Değiştirmek istediğiniz eylemin yanındaki düğmeye tıklayın.
4. Yeni kombinasyona basın.
5. `Esc` ile iptal edin; **Temizle** ile varsayılana döndürün.

Atama penceresi açıkken diğer uygulama kısayolları devre dışıdır.

## Sorun giderme

- **Kısayol çalışmıyor:** Başka bir uygulama aynı kombinasyonu kullanıyor
  olabilir. Farklı bir tuş deneyin.
- **Kayıt sırasında kısayol çalışmıyor:** Oyun/uygulama yönetici olarak
  çalışıyorsa AptozaQ3'ü de yönetici olarak çalıştırın.
- **Çizim kısayolu metin alanında çalışmıyor:** Bu beklenen davranıştır; metin
  alanından çıkın.
- **Tuş adı görünmüyor:** Türkçe/klavye düzeni farklı olabilir; fiziksel tuşu
  kullanın ve atamayı yeniden yapın.
