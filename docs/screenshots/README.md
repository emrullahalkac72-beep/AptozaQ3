## Kurallar

- PNG veya WebP kullanın; JPEG'de metin kenarları bozulabilir.
- Kişisel bilgileri, gerçek dosya yollarını ve kullanıcı adlarını gizleyin.
- Karanlık tema varsayılan olduğu için koyu tema görselleri tercih edin.
- Pencereyi 1600×900 civarında tutun; aşırı büyük görseller depoyu şişirir.
- Tek görsel 1 MB'ı geçmesin; gerekirse WebP'ye dönüştürün.
- Ekran görüntüsü alırken imleci ve gereksiz bildirimleri gizleyin.
