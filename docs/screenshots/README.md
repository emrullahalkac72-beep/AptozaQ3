# Ekran Görüntüleri

Bu klasör README ve sürüm notlarında kullanılacak görselleri barındırır.
Görselleri ekledikten sonra aşağıdaki adları kullanmanız önerilir.

## Önerilen dosyalar

| Dosya | İçerik | Önerilen boyut |
|---|---|---|
| `record.png` | Kayıt sekmesi ve kayıt ayarları | 1600×900 |
| `draw.png` | Çizim araç paneli ve `Kalem` çizimi | 1600×900 |
| `timeline.png` | Timeline, klipler ve geçişler | 1600×900 |
| `audio.png` | Ses editörü ve efekt paneli | 1600×900 |
| `image-to-video.png` | Görselden video aracı | 1600×900 |

## Kurallar

- PNG veya WebP kullanın; JPEG'de metin kenarları bozulabilir.
- Kişisel bilgileri, gerçek dosya yollarını ve kullanıcı adlarını gizleyin.
- Karanlık tema varsayılan olduğu için koyu tema görselleri tercih edin.
- Pencereyi 1600×900 civarında tutun; aşırı büyük görseller depoyu şişirir.
- Tek görsel 1 MB'ı geçmesin; gerekirse WebP'ye dönüştürün.
- Ekran görüntüsü alırken imleci ve gereksiz bildirimleri gizleyin.
